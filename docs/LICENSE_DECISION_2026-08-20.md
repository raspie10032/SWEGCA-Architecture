# SWEGCA license decision

- decision date: 2026-08-20
- copyright holder: PARK DONGJUN
- source-code license: Mozilla Public License 2.0 (`MPL-2.0`)
- repository visibility at decision time: private

PARK DONGJUN selected MPL-2.0 for the standalone SWEGCA source repository. The
complete, unmodified Mozilla license text is stored in `LICENSE`; `NOTICE`
contains the Exhibit A source-form notice and copyright statement; and
`pyproject.toml` declares the SPDX identifier `MPL-2.0`.

MPL-2.0 is file-level copyleft. Distribution of modified covered source files
must preserve MPL-2.0, required notices, and source availability obligations.
Separate files in a Larger Work may use other terms as allowed by the license.

This decision does not make the private GitHub repository public. Repository
visibility remains a separate PARK DONGJUN decision. It also does not select the
arXiv manuscript distribution license: the paper license must still be chosen
separately during author self-submission.
