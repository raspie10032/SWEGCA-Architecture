# SWEGCA journal preprint snapshot — 2026-08-25

This directory preserves the manuscript snapshot prepared for submission to
*Cognitive Systems Research*. It is a pre-peer-review preprint, not an accepted
manuscript or published journal article.

## Public files

- `SWEGCA_anonymized_manuscript.pdf`: verified 11-page anonymous PDF
- `main.tex`: exact anonymous manuscript source
- `references.bib`: exact bibliography used by the source
- `HIGHLIGHTS.txt`: journal highlights
- `ANONYMIZATION_AUDIT.md` and `PDF_VALIDATION.json`: release checks
- ledgers and reproducibility notes: claim, component, result, lineage, and
  license boundaries for this snapshot

The title page, cover letter, author contact data, portal metadata, and private
working-repository history are intentionally excluded. The repository itself
identifies the author, so public availability may make author identity
discoverable even though the submitted manuscript file is technically
anonymous.
